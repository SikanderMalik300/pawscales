# PawScales logo pack (2026-10-11)

Original logo for PawScales: a white paw whose main pad holds a small scale dial (the "Scales" in PawScales), on a spruce-green rounded square, plus the wordmark "PawScales" in Figtree 600 ("Paw" in ink #111312, "Scales" in brand #1F5C45). Text is converted to outlines, so no font is needed to display it.
